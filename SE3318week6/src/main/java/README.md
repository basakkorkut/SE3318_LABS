# Eldoria Game

A simple fantasy RPG simulation developed as part of the Software Construction course (SE3318).

## Description
Eldoria is a magical land where heroes accept quests and battle enemies. This project showcases core Object-Oriented Programming principles using Java and Maven, along with version control using Git.

## Features
- Abstract class: `Character`
- Subclasses: `Hero`, `Enemy`
- Interface: `Questable`
- Supporting classes: `QuestBoard`, `BattleManager`
- Custom hero classes: `Mage`, `Warrior`

## Technologies
- Java
- Maven
- Git & SourceTree
